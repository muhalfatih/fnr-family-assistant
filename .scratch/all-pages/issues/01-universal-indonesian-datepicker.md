# 01: Universal Indonesian DatePicker Component

**What to build:** A reusable, fully accessible popover DatePicker component using Radix UI Popover and `react-day-picker` with complete Indonesian locale support (`date-fns/locale/id`), standard `h-9` trigger styling, and clear date formatting (`dd MMMM yyyy`).

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] Reusable `DatePicker` component in `src/components/ui/date-picker.tsx`.
- [x] Integration with `date-fns/locale/id` for Indonesian month names and day headers.
- [x] Standard form trigger button with calendar icon, `h-9 text-xs` dimensions, and "Pilih tanggal" placeholder.
- [x] Keyboard navigable popover with auto-close on selection.
