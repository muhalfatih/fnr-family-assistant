# 02: Design Tokens, Strict Spacing Scale & Tabular Numerals

**What to build:** Standardized global design token system establishing a strict 8pt spacing rhythm (`p-5` for panels, `p-4` for compact items, `space-y-6` for section gaps), universal `rounded-xl` card radius with single elevation borders, and `tabular-nums` formatting on all financial metrics, percentages, and latency timers.

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] Universal outer container spacing `max-w-7xl mx-auto p-4 sm:p-6 lg:p-8 space-y-6`.
- [x] Single elevation card styling `rounded-xl border border-border/80 bg-card` with zero heavy shadows.
- [x] Standard control dimensions `h-9 text-xs rounded-md` for inputs and action buttons.
- [x] `tabular-nums` applied to all monetary values, percentages, dates, and millisecond counters.
- [x] Zero em-dash (`—`) compliance across all labels and typography.
